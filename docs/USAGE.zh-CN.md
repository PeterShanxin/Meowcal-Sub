# 使用 Meowcal Sub · 妙影

[返回项目](../README.zh-CN.md) · [English](USAGE.md)

Meowcal Sub · 妙影翻译的是**选定屏幕区域中的可见文字**，不是语音。
视频需要已经显示中文、日文、韩文、英文、西班牙文、法文或德文字幕。

本指南适用于 Meowcal Sub · 妙影 v0.10.0。
各版本变化见[版本说明](releases/)。

## 安装

从[最新应用发布页](https://github.com/PeterShanxin/Meowcal-Sub/releases/latest)下载安装包。
Intel / AMD Windows 电脑选择 **x64**，Windows on ARM 电脑选择 **ARM64**。
通常使用 `.exe` 安装程序，也可下载 `.msi` 包。
GitHub 的 **Source code** 压缩包面向开发者，不能直接安装应用。
不需要另外安装 Rust、Node.js 或 Meowcal Core。

应用目前为 Windows 11 公开测试版。引擎要求 Windows 报告的系统总内存至少
**8 GiB**；安装需要磁盘空间时，引擎安装盘至少应有 **3 GiB 空闲空间**。
这些门槛来自[引擎清单](../core/config/engine-manifest.v1.json)，不代表性能保证。
还应为视频播放器和其他应用留出内存。

首次设置约需下载 **1.1 GB** 本地翻译资源。这是下载量估计，**不是安装后的磁盘总需求**；
解压、缓存和保留的运行环境版本还需要额外空间。

### 校验下载

从**同一个应用发布版本**下载安装包和 `SHA256SUMS.txt`。
在 PowerShell 中计算已下载文件的哈希，例如：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\Meowcal.Sub_0.10.0_x64-setup.exe"
```

下载其他版本或架构时，请使用实际文件名。将完整哈希与 `SHA256SUMS.txt` 中
对应文件名的条目比对，字母大小写不影响结果。不一致时，停止安装。
匹配只说明文件与发布的校验值一致，并非对软件安全性的独立保证。

安装包未使用 Authenticode 签名，Windows SmartScreen 可能显示“未知发布者”。
不要全局关闭 SmartScreen 或其他安全防护。决定运行安装包前，确认源码和发布来源。
应用内更新签名是另一种机制，不等同于 Windows 发布者签名。

## 第一次翻译

首次设置在准备引擎前要求同意模型条款。
完成后在首页选择字幕语言。向导显示 Core 报告的当前操作和下载进度。
已配置的安装会直接显示完成页面；启动引擎时，Core 仍会校验资源。
接受模型条款后，Core 可以复用符合条件的本地资源。取消首次设置会退出应用。

1. 完成设置向导，或在首页点击 **设置翻译**，让向导下载并测试本地引擎。
2. 在首页选择 **原字幕**（原字幕语言）和 **翻译为**（目标语言）。
3. 将主窗口移到播放视频的屏幕。
4. 点击 **选择字幕区域**，打开字幕区域选择器。
5. 拖动圈选原字幕，或按 <kbd>Enter</kbd> 在屏幕下方放置建议选框。
   拖动选框或边缘控制点可以移动或调整大小。双行字幕要完整框入两行。避开播放器控件、无关文字和译文将要显示的位置。
6. 点击 **确认并开始**，或按 <kbd>Enter</kbd>。**重新框选** 可重新选择区域。
   点击 **退出** 或按 <kbd>Esc</kbd> 返回首页，不开始翻译；尚未画出选框时，点击 **取消**。

首次启动时，模型预热需要更多时间。译文显示在选区附近的悬浮层中。
悬浮层有两个控件；控件淡出后，将鼠标移入悬浮层，或按 <kbd>Alt</kbd>+<kbd>Tab</kbd> 切换到它。
**字幕样式** 调整字号和深色／浅色底板；**退出翻译** 停止翻译并返回首页。
首页的 **停止翻译** 也可以结束会话。

首页通过主按钮显示准备状态：准备期间禁用按钮并显示加载动画；
准备好后点击 **选择字幕区域（Select subtitle area）** 打开选区。
选择器提供 **确认并开始（Confirm and start）**、**重新框选（Redraw）**、
**保存并退出（Save and exit）** 和 **退出（Exit）**。
鼠标可以移动或缩放选框，不再使用方向键移动或缩放。
首页准备好后显示观看提示；当前屏幕有有效的已保存区域时，
**使用已保存区域开始（Start with saved area）** 可直接开始翻译。
修复提示和其他需要操作的消息仍会显示。

如需只调整区域而不开始翻译，选择 **选择字幕区域**，再点击 **保存并退出**；
之后可使用 **使用已保存区域开始**。

选区是固定屏幕区域，不会跟踪视频。移动视频、调整大小或切换全屏后，需要重新圈选。

### 多显示器

连接多个显示器时，首页会显示简短提示。选择器打开时，主窗口大部分所在的屏幕
用于选区、识别和悬浮字幕。翻译开始后，即使移动主窗口，捕获屏幕也不会改变。
切换屏幕时，先停止翻译，移动主窗口，再重新圈选。

捕获屏幕断开，或位置、分辨率、缩放改变时，翻译会停止，悬浮层隐藏。
重新连接不会自动恢复捕获，需要再次圈选。重启后，只有原屏幕、边界和缩放均未改变，
且主窗口位于该屏幕，应用才恢复已保存区域。

## 界面语言

在 **设置 → 界面语言（Settings → App language）** 中选择
**跟随系统（System default）**、**English** 或 **简体中文**。
默认跟随系统；中文系统语言使用简体中文，其他语言使用英文。
切换立即生效，偏好会保存，下次启动继续使用。
中文界面显示 **Meowcal Sub · 妙影**，英文界面显示 **Meowcal Sub · 妙影**。

界面语言独立于 **原字幕（Original subtitles）** 和 **翻译为（Translate into）**。
例如，界面可以使用简体中文，同时将日语字幕翻译成英语。
更改界面语言不会改变字幕语言组合，也不会改写已捕获的原文或译文。

## 设置

**设置 → 关于（Settings → About）** 显示应用版本、提供方、
项目链接及模型许可和使用条款。首次设置仍会展示提供方信息，并要求同意模型条款。
设置修改后自动保存，保存成功提示显示四秒。

| 设置 | 作用 | 何时调整 |
| --- | --- | --- |
| **翻译任意文字** | 翻译网页、菜单、游戏等可读文字，不限于形似字幕的文本。默认关闭。 | 翻译幻灯片或应用时开启；观看视频时保持关闭，避免将水印、计时器和场景文字送去翻译。 |
| **保持名称一致** | 使用最近的原文作为上下文，帮助统一人名和术语。默认关闭。 | 仅在人名反复变化时尝试；上下文可能导致模型重复上一句。 |
| **运行方案 → 自动** | 使用 PP-OCRv6 识别；引擎允许时使用显卡翻译。 | 适用于大多数电脑的默认配置。 |
| **运行方案 → 兼容** | 使用 Windows OCR 和 CPU 翻译。 | 译文乱码、显卡驱动异常或电脑卡顿时使用。 |
| **运行方案 → 自定义** | 高级设置与两种预设均不一致时显示。 | 无法直接选择；选择一个预设可恢复该配置。 |
| **高级 → 文字识别** | 选择 **PP-OCRv6**（内置，无需 Windows 语言）或 **Windows OCR**。韩语始终使用 Windows OCR。 | PP-OCRv6 容易误读某种字幕时，尝试 Windows OCR。 |
| **高级 → 仅使用 CPU 运行引擎** | 禁用 GPU 卸载；修改后重启引擎。 | 希望保留 PP-OCRv6，同时解决翻译乱码或卡顿时使用。CPU 翻译可能较慢。 |
| **高级 → 识别质量** | 仅 Windows OCR 显示：**快速**、**均衡**、**精确**。 | 文字难以识别且电脑有余量时尝试精确。 |
| **引擎与更新 → 翻译引擎** | 显示引擎状态；**测试** 在本机运行样例翻译；**修复** 校验并恢复引擎。 | 首页要求修复或样例失败时使用修复。 |
| **自动检查更新** | 启动后自动检查更新，至多每天一次。 | 只想手动检查时关闭。 |
| **开发者选项 → 开发者模式** | 显示 **显示字幕诊断信息**、引擎阶段和支持代码。 | 仅用于故障排查。 |

Windows OCR 需要原字幕语言对应的 Windows 识别语言。
缺少时，首页显示 **安装识别语言包**。
CPU 翻译期间，PP-OCRv6 使用两个 CPU 线程，为翻译留出资源；GPU 翻译时最多使用四个。

## 应用当前在做什么

### 首页

| 首页提示 | 含义 | 操作 |
| --- | --- | --- |
| **正在准备** | 检查引擎、识别语言和已保存区域。 | 等待。 |
| **设置本地翻译** | 尚未安装引擎。 | 点击 **设置翻译**。 |
| **正在预热翻译引擎** | 正在加载或校验模型。 | 等待准备完成。 |
| **正在等待引擎** | 引擎正在安装、修复或执行其他操作。 | 等待完成后重试。 |
| **翻译引擎需要修复** | 引擎检查失败；设置仍保留。 | 点击 **修复引擎**；修复失败时记录支持代码。 |
| **安装识别语言包** | Windows OCR 缺少识别语言。 | 点击 **安装识别语言包**。 |
| **请在选区窗口中确认…** | 选区窗口已打开。 | 在选择器中确认或取消。 |
| **正在启动翻译** | 正在为会话预热引擎。 | 等待。 |
| **字幕翻译已开启** | 正在显示字幕。 | 点击 **停止翻译** 结束。 |

会话意外结束时，首页提示翻译已意外停止，需要重新开始。
文字识别连续三次失败时，提示文字识别没有响应，需要返回首页重新开始翻译。

### 悬浮字幕

| 悬浮层显示 | 含义 | 操作 |
| --- | --- | --- |
| 一行译文 | 最近完成的字幕翻译。 | 无需操作。 |
| **正在准备翻译…** | 引擎仍在预热或恢复。 | 等待。 |
| **正在等待字幕…** | 识别正常，但区域内已连续 15 秒没有文字。 | 确认字幕位于选区内；文字恢复后提示消失。 |
| **翻译引擎已停止。** | 引擎恢复失败；字幕仍需翻译时，应用在 30、60、120 秒后重试，之后每 300 秒重试。 | 等待，或点击 **退出翻译**，再修复引擎。 |
| **翻译已中断。** | 捕获、识别或会话已中断。 | 点击 **退出翻译**，然后重新开始。 |

单句翻译过慢或引擎短暂失败时，当前译文会保留；原字幕仍可见时，应用会重试。
短暂间隙和成功恢复不会显示额外提示。

## 字幕处理方式

- **顺序。** 字幕按出现顺序翻译和显示。新字幕需要两次一致的识别结果才会进入队列，单帧误读不会产生新的一句。
- **快速对白。** 上一句显示时，下一句可以开始翻译。译文保留足够的阅读时间，但不超过原字幕的显示时长（最多四秒），避免不断积累延迟。如果仍然落后 15 秒或积压 32 句，应用跳过等待中的句子，从当前字幕继续。
- **暂停与继续。** 视频暂停时，相同字幕不会重复翻译，译文保留在屏幕上。恢复播放后，正常翻译下一句。
- **重复字幕。** 同一文字消失后再出现，会重新翻译和显示。没有空白间隔的两句相同文本视为同一句；大小写、空格和末尾标点变化不会生成新句，单词、数字或字符变化会。
- **画面变化。** 视频移动或缩放不会移动选区，需要重新圈选。会话中改变选区会重启会话，丢弃仍在处理的旧译文。
- **片尾和标牌。** 正常模式过滤水印、计时器和移动的场景文字；快速变化的人名列表（例如片尾字幕）仍可能被翻译。

## 故障排查

| 现象 | 先检查什么 |
| --- | --- |
| 首页提示缺少识别语言 | 当前使用 Windows OCR（韩语、兼容方案，或手动选择 Windows OCR）。安装原字幕语言的 OCR 组件，不是目标语言。 |
| 首页提供 **修复引擎** | 使用此操作校验并恢复引擎；失败时保留支持代码。 |
| 设置报告 `ENGINE_INCOMPATIBLE` 或 `ENGINE_DISK_SPACE` | 检查 Windows 11、8 GiB 系统内存和安装盘 3 GiB 空闲空间要求。缺少架构对应的运行环境或不支持的安装路径也可能导致不兼容；反馈时提供完整支持消息。 |
| 漏字或误读 | 确认字幕可见、选区对齐且包含每一行；排除播放器控件和悬浮译文。尝试更大、更清晰的字幕，或另一种文字识别引擎。 |
| 可读的非字幕文字被忽略 | 正常模式筛选形似字幕的文字；确实需要翻译此类内容时才打开 **翻译任意文字**。它不会提高识别本身的准确率。 |
| 同一句被翻译两次 | 两次识别之间字幕短暂消失，或 OCR 返回了空帧。将选区紧贴字幕。 |
| 译文乱码或电脑卡顿 | 使用 **运行方案 → 兼容**，或开启 **高级 → 仅使用 CPU 运行引擎**。引擎会在 CPU 上重启；反馈时附支持代码、GPU 型号和驱动版本。 |
| 翻译慢或逐渐落后 | 首次预热需要时间。关闭占用 CPU 或内存较多的应用；繁忙的电脑上 CPU 翻译可能明显变慢。缩小选区。 |
| 捕获空白或不完整 | 受保护内容或播放器显示模式可能无法捕获。首页可能提示兼容捕获及受保护视频无法读取。用普通窗口播放不受保护的本地片段测试；应用不会绕过捕获保护。 |
| 应用显示已是最新版 | 将安装版本与应用发布版本比较，不要与 `core-v...` 运行环境标签比较。代码已合并不代表应用已发布。 |

在 **设置 → 引擎与更新 → 检查更新** 手动检查更新。
自动检查在启动时进行，至多每天一次。检查不会下载应用更新；
只有 **下载并安装** 才会下载并安装。

可用更新在 **更新内容** 下显示最多三条格式化摘要，不使用独立滚动框。
**完整更新说明 ↗** 在浏览器中打开该版本的完整 GitHub 发布说明。
没有摘要时，该链接仍可用。

## 日志与诊断

开启日志时，应用每次启动写入一份会话日志，并在启动时删除超过七天的 `.log` 文件。

**设置 → 本地日志** 提供三个级别：

- **关闭**：设置加载后，停止新增诊断事件和捕获证据。
- **基本**（默认）：记录运行诊断，不保留截图或字幕文字。
- **详细**：还会在本机保存原始捕获区域、实际 OCR 输入 PNG、原始识别文字与几何信息，以及原文和译文。选择此项表示主动同意保留可能含隐私的屏幕内容；不会上传。

会话文件名为 `meowcal-sub_<dev|prod>_<date>_<time>_<pid>.log`，
每条记录带有 `[dev]` 或 `[prod]` 标记。直接安装版的日志位于
`%APPDATA%\com.meowcal.sub\logs`，可将路径粘贴到文件资源管理器。
普通 `.log` 文件仍采用启动时清理超过七天文件的规则。
详细日志证据位于 `logs\verbose`，独立总量上限为 **256 MiB**。
写入新记录前，应用按需删除最旧的完整或未完成证据记录，不删除无关文件。
单条记录超过上限、写入锁超过两秒、发现异常文件或写入失败时，会跳过证据记录，不中断翻译。
详细日志没有额外的按年龄清理规则。关闭后停止新增记录，但不删除已有文件；
不再需要时，可删除 `verbose` 文件夹内的私人内容。分享前检查文件。
保存 PNG 可能降低捕获速度，请仅在短时间排查时使用详细日志。

默认日志记录耗时、字符数、队列长度、引擎状态、支持代码和错误代码，
设计上不包含字幕原文和译文。分享前仍应检查日志。

以下两种诊断可能暴露屏幕内容，仅用于本地排查：

- **设置 → 开发者选项 → 开发者模式 → 显示字幕诊断信息** 在实时字幕旁显示识别细节。开启时拍摄的截图会包含这些信息。
- 环境变量 `MEOWCAL_BAND_LOG` 将字幕区域判断写入本地 JSONL，不含文字；额外设置 `MEOWCAL_BAND_LOG_TEXT=1` 会记录**完整的识别原文**。不要公开这些文件。

## 安全地反馈问题

1. 记录应用版本（**设置 → 关于**）、Windows 构建号（`winver`）及 x64 / ARM64 架构。
2. 记录原字幕语言、目标语言、**运行方案** 和 **文字识别** 引擎。
3. 首页或设置显示支持代码时，复制代码。
4. 提供可复现步骤，用文字描述视频，不必分享视频本身。
5. 如需日志，只复制相关行，并删除不想公开的内容。

通过[问题入口](https://github.com/PeterShanxin/Meowcal-Sub/issues/new/choose)反馈。
不要发布捕获的字幕、观看内容截图、API key 或含有这些内容的原始日志。
可以提供只显示悬浮层自身控件的截图。安全漏洞按 [SECURITY.md](../SECURITY.md) 私下报告。

卡住时依次尝试：**停止翻译** 或 **退出翻译**；
**修复引擎**；重启应用；选择 **运行方案 → 兼容**。

## 常见问题

### 能为没有字幕的视频生成字幕吗？

不能。本应用用 OCR 读取画面文字，不转录语音。
寻找字幕文件或需要跟随播放进度的字幕会话时，可了解独立项目
[Meowcal Sub 2](https://github.com/PeterShanxin/Meowcal-Sub-2)。

### 可以离线使用吗？

安装好本地引擎后，OCR 和翻译可以离线运行；使用 Windows OCR 时，还需要先安装识别语言。
设置、修复下载、缺少的 Windows 语言组件以及更新检查和下载需要联网。
视频服务有自己的联网要求。

### 不同架构的 GPU 支持有何区别？

**ARM64：**Adreno 加速仅对验证过的硬件／驱动组合启用，其他配置使用 CPU。
GPU 就绪检查超时后，可在原有启动时限内重试一次 CPU。

**x64：**随应用提供的运行环境在独立显卡上使用 Vulkan。
仅有集成显卡或没有 GPU 的电脑使用 CPU；已测过的一款集成显卡比 CPU 更慢。
GPU 就绪超时或样例翻译失败后，可在原有启动时限内重试一次 CPU。
独立显卡的 Vulkan 驱动不可用时，也可能在应用显示 GPU 的情况下实际使用 CPU。

**两种架构**都可以通过 **设置 → 高级 → 仅使用 CPU 运行引擎**
（**兼容** 配置的一部分）禁用 GPU 卸载。修改后重启引擎；CPU 翻译可能较慢。

两种方式都需要前述系统内存。详见[Core 性能证据](CORE_PERFORMANCE.md)；
这些是特定条件下的测量，不是通用延迟承诺，也不预测每台电脑的表现。

### 可以翻译网页或幻灯片吗？

设置中的 **翻译任意文字** 放宽字幕专用筛选，可翻译选区内的其他可读文字，默认关闭。
效果仍取决于文字清晰度、语言支持和屏幕捕获是否可用。

### 需要其他 Meow 应用吗？

不需要。Meowcal Sub 使用随应用提供、固定版本的 [Meowcal Core](../core/README.md)。
MeowWatch 用于一起观看；Sub 2 使用另一种字幕工作流。两者都不是 Sub 1 的运行前提。
