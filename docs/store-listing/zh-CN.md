# Meowcal Sub · 妙影

## 简短描述

把屏幕上的字幕，翻译成你想读的语言。本地识别、本地翻译，译文悬浮显示。全本地运行 · 保护隐私 · 无付费，无需账号或 API 密钥。

## 描述

看视频、玩游戏时，让屏幕上的字幕变成你能读懂的语言。Meowcal Sub · 妙影识别屏幕上已有的字幕，用本地 AI 翻译，并将译文悬浮显示在画面上。

选好原字幕和译文语言，框选字幕区域，即可开始观看。下次可以直接使用已保存的区域。字幕位置、字号和背景均可调整，适应不同画面。

全本地运行
屏幕捕获、文字识别和 AI 翻译均在你的电脑上完成。首次下载模型和运行时后，即可离线翻译。无需账号、API 密钥或订阅，也没有按次翻译费用。

适合你的屏幕
• 内置 PP-OCRv6 文字识别，也可选择 Windows OCR。
• 在应用所在的显示器上选择字幕区域。
• 开启“翻译任意文字”，翻译选定区域内的整段文字。
• 界面支持 English 和简体中文，与字幕翻译语言独立设置。
• 调整字幕字号，选择深色或浅色背景。

开始使用
支持 Windows 11，x64 或 ARM64 处理器，需要至少 8 GB 内存和 3 GB 可用磁盘空间。首次设置需联网下载约 1.1 GB 的模型和运行时，并需要 Microsoft Edge WebView2。仅在使用 Windows OCR 时需要相应的系统 OCR 语言资源，韩语识别使用 Windows OCR。应用通过 Microsoft Store 更新。

## 功能

- 本地字幕识别与 AI 翻译
- 悬浮字幕，字号和背景可调
- 保存字幕区域，下次直接开始
- English / 简体中文双语界面
- 首次设置后可离线翻译
- 无需账号、API 密钥、订阅或按次付费
