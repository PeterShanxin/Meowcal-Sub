# Meowcal Sub

## Short description

Translate subtitles already on your screen. Local text recognition and AI translation, with a floating subtitle overlay. No account, API key, or subscription.

## Description

Watch with subtitles you can read. Meowcal Sub translates visible subtitles in videos, games, and desktop apps, and displays the translation in a floating overlay.

Choose the original and translation languages, select the subtitle area, and start watching. Next time, start with your saved area. Move the overlay and adjust its text size and background to suit what you are watching.

FULLY LOCAL
Screen capture, text recognition, and AI translation run on your PC. After the initial model and runtime download, you can translate offline. No account, API key, subscription, or per-translation fees.

MADE FOR YOUR SCREEN
• Read subtitles with built-in PP-OCRv6 text recognition, or choose Windows OCR.
• Select an area on the display where the app is open.
• Translate a selected passage with Translate any text.
• Use the app in English or Simplified Chinese, independently of your subtitle languages.
• Adjust subtitle size and choose a dark or light background.

GET STARTED
Windows 11 on x64 or ARM64, at least 8 GB RAM and 3 GB free disk space. Initial setup downloads approximately 1.1 GB of model and runtime files and requires an internet connection. Microsoft Edge WebView2 is required. Windows OCR language resources are needed only when using Windows OCR, including for Korean. App updates come through Microsoft Store.
