# Meowcal Sub · 妙影 v0.10.0

[English](v0.10.0.md)

**Meowcal Sub 现在支持英文和简体中文界面，并以叠层字幕卡片作为新的品牌图标。**
这次更新也改进了首次设置、字幕选区、设置页面和更新说明，让日常使用更顺手。

## 主要更新

- **用熟悉的语言操作。** 在设置中选择跟随系统、English 或简体中文，立即切换并保存偏好。界面语言与字幕语言独立；设置向导、悬浮字幕、选区、通知和更新控件均支持双语（#324）。
- **认识 Meowcal Sub · 妙影。** 中文界面在原有品牌名后加入「妙影」，英文仍为 Meowcal Sub。应用、托盘和安装包统一采用圆润的叠层字幕卡片图标，中英文 README 也有各自的品牌展示和使用指南（#324）。
- **更顺手地开始观看。** 首次设置聚焦模型条款、下载进度和示例测试；首页提供“选择字幕区域”和“使用已保存区域开始”。选区可“保存并退出”，版本和许可信息集中在“关于”中（#322、#323）。

## 修复与改进

- 选区、启动和提示出现时，首页布局保持稳定；设置保存后显示短暂的成功提示（#323）。
- 本地日志支持关闭、基本和详细三个级别，默认使用基本日志。主动开启详细日志后，可在本机保存截图和字幕文字，单独限制为 256 MiB（#317、#320）。
- 应用更新显示最多三条易读摘要，并提供完整更新说明链接（#321）。
- 中英文安装、故障排查和常见问题指南与当前界面操作同步（#324）。

## 已知限制

- 应用翻译屏幕上可见的文字，不识别语音。OCR 和翻译仍可能出错；本次继续使用 Meowcal Core v0.2.2 和现有 HY-MT 模型。
- 详细日志可能包含私人屏幕内容，也可能降低捕获速度。关闭后停止新增记录，但不会删除已有文件；分享前请检查内容。
- GitHub 安装包未使用 Authenticode 签名，Windows SmartScreen 可能显示“未知发布者”（#62）。
- ARM64 GPU 翻译仍以已验证的 Adreno X1-85 / 31.0.148.0 驱动为支持边界（#105、#215）。
