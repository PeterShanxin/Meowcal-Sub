# Meowcal Sub v0.6.1

This release candidate focuses on a reliable first run and a stable subtitle
overlay for real episode viewing.

## Fixes and improvements

- Opens the guided local-translation setup automatically on the first real app
  launch and records completion only after setup succeeds.
- Keeps the Meowcal logo bundled correctly throughout install and repair.
- Uses varied subtitle-style sample lines for every supported source language
  and tests the pair currently selected by the user.
- Keeps source and target languages distinct so a healthy same-language result
  cannot be misreported as an engine failure.
- Reworks the native Windows overlay region so the capture area remains a hole,
  visible controls keep their real rounded shapes, and a WebView2 transparency
  regression cannot create a white frame or full-screen white window.
- Extracts native overlay clipping from the legacy command hotspot and lowers
  the enforced `commands.rs` maintainability ceiling from 2,432 to 2,279 lines.

## Before installing

- Windows 11 is the supported target.
- Choose ARM64 for Snapdragon/ARM Windows PCs and x64 for Intel or AMD PCs.
- Installers are not yet code-signed. Windows SmartScreen may show an
  unknown-publisher warning; verify downloads against `SHA256SUMS.txt`.
- The local translation runtime and model require a one-time download of about
  1.1 GB.

## Validation status

The full automated repository gate and current-head review passed. This draft
still requires a fresh installed-app check of first-run setup, overlay behavior,
and a real episode before publication.
