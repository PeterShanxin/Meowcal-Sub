# Meowcal Sub v0.8.0

This release redesigns every Meowcal Sub window, stops real subtitles from being
held back when consecutive lines look alike, and moves recognition and local
translation into a separate, versioned runtime.

## Highlights

- **New design.** The main window, setup, area selector, and overlay share one
  look. Home has three tabs - Home, Subtitle style, and Settings - and its
  status names the current state.
- **Subtitle style** (was Overlay appearance). Choose a text size from 20 to
  48 px and a Dark or Light plate; the preview matches the live overlay. The
  default size is 28 px where no size was saved. The overlay's gear menu offers
  the same two choices.
- **Setup.** Progress counts finished stages. A failure names the stage that
  failed and offers Try again and Copy details. Closing setup once keeps it from
  reopening on every launch; Home's Set up action brings it back.
- **Area selector.** Enter places a box, arrow keys move it, and Shift+arrow
  keys resize it. A selection that is too small, or one that cannot be saved,
  is explained in place.
- **Settings.** Plain-language grouped settings. Repair becomes the main action
  when the engine is unhealthy. Subtitle diagnostics, which show recognised
  text, are under Developer options.

## Fixes

- Subtitles with a similar length and position to the previous line are no
  longer held as "not dialogue" (#95). New lines are now recognised by their
  text, not only by their shape on screen.
- The overlay opacity slider is removed: the overlay never applied it.

## Windows / ARM64 notes

- Screen text recognition and the local translation engine run in a separate
  Meowcal Core process (core-v0.1.0), and each installer carries the Core build
  verified for its architecture.
- GPU acceleration remains limited to the validated Qualcomm Adreno X1-85 with
  driver 31.0.148.0; other ARM64 hardware continues to use the CPU policy.

## Known limitations

- This release was tested on Windows 11 ARM64. The x64 installers pass the
  automated build and contract checks but were not run on x64 hardware.
- On ARM64 with GPU acceleration, the first start after its shader cache is
  cleared can take about 30 seconds before translation is ready, and the first
  subtitles may time out.
- Subtitles made only of numbers can resemble a counter and wait about two
  seconds before they are shown.
- General text is translated with the same prompt as subtitles, so rows of
  short UI labels can come back loosely translated (#181).
- With **Translate any text** on, deciding whether on-screen text has changed
  still uses the rules built for subtitles (#187).
- Installers are not Authenticode code-signed, so Windows SmartScreen may
  still show an unknown-publisher warning.

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The local runtime and model require a one-time
download.
