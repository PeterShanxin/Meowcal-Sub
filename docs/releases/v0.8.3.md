# Meowcal Sub v0.8.3

This release detects corrupt translation output during use and restores
translation on CPU after confirming an inference failure.

## Fixes

- **Recovery during translation.** An engine can remain responsive while its
  output becomes unusable. Suspicious results now trigger a bounded independent
  check; a failed check or repeated strong corruption switches inference to CPU
  for the rest of the application session (#105).
- **Reject corrupt output before display.** Symbol debris and repeated Chinese,
  Japanese, or Korean sequences are rejected before entering subtitles, cached
  translations, or context. Source-aware checks preserve legitimate repetition.
- **Stable CPU recovery.** Concurrent failures share one recovery attempt, and
  the CPU choice survives Core restarts. Stopping translation cancels recovery.

## Windows / ARM64 notes

- Each installer carries Meowcal Core v0.1.3 for its architecture.
- The existing memory-headroom gate remains active. GPU acceleration remains
  limited to the validated Adreno X1-85 with driver 31.0.148.0; other ARM64
  hardware uses CPU inference.
- Windows 11 ARM64 native testing completed a 120-second authored subtitle
  fixture with all 30 cues translated. A controlled GPU process exit followed
  by an inference-quality report recovered on CPU in 3.245 seconds. These tests
  do not establish general movie reliability or reproduce a natural GPU fault.

## Known limitations

- The cause of the Adreno numerical corruption remains unresolved. CPU fallback
  reduces GPU exposure but is not proven to prevent the reported
  `SOC_CRITICAL_DEVICE_REMOVED` Windows stop error (#215).
- A static watermark can be readmitted after a brief OCR dropout (#223).
- The x64 installers receive automated build and contract checks; physical x64
  and long real-media playback were not validated for this release.
- First translation waits for model loading, which can take longer under memory
  pressure. CPU inference latency varies by device.
- General screen text still shares the subtitle prompt and change-detection
  rules (#181, #187).
- Installers are not Authenticode code-signed. Windows SmartScreen may show an
  unknown-publisher warning.

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The local runtime and model require a one-time download;
verified files from an earlier Core version can be reused.
