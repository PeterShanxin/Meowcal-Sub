# Meowcal Sub v0.7.0

This release lets Meowcal Sub translate more than subtitles, and fixes a crash
when the app re-adopts an engine it had lost track of.

## Highlights

- New setting: **Translate any text** (Settings -> Translation). Off by default,
  the app only translates text that behaves like a subtitle track. Turn it on to
  translate any readable text in the capture region - web pages, app windows,
  game text, slides. The setting applies from the next Start.
- With it on, text that holds still on screen is translated once and then left
  alone; it is not sent again on every capture.

## Fixes

- The app no longer crashes on launch when its settings have lost the engine
  registration but the engine is still installed. Startup now re-adopts the
  installed engine as intended instead of overflowing the main thread's stack.
- Overlay hints no longer mention subtitles where they apply to any text: "No
  text in the selected area" and "Text in this area could not be read".

## Windows / ARM64 notes

- No changes to the ARM64 GPU-offload path since v0.6.9. GPU acceleration
  remains limited to the validated Qualcomm Adreno X1-85 with driver
  31.0.148.0; other ARM64 hardware continues to use the CPU policy.

## Maintenance

- Windows installers for both architectures are now built on GitHub-hosted
  runners native to each architecture.

## Known limitations

- General text is translated with the same prompt as subtitles, so rows of
  short UI labels can come back loosely translated (#181).
- With **Translate any text** off, some real subtitles are still held as "not
  dialogue", most often when consecutive lines have a similar length (#95).
- Editing on-screen text so that it becomes the start of the previous line can
  keep the previous translation until the text changes further.
- Installers are not Authenticode code-signed, so Windows SmartScreen may
  still show an unknown-publisher warning.

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The local runtime and model require a one-time
download.
