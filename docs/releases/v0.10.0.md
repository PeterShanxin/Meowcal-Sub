# Meowcal Sub v0.10.0

[简体中文](https://github.com/PeterShanxin/Meowcal-Sub/blob/v0.10.0/docs/releases/v0.10.0.zh-CN.md)

**Meowcal Sub now speaks English and Simplified Chinese, with a refreshed subtitle-card identity.**
This release also makes setup, subtitle selection, settings and update notes easier to use.

## ✨ Highlights

- 🌐 **Use the app in your language.** Choose System default, English or 简体中文 in Settings; the interface switches immediately and remembers your choice. Subtitle languages stay independent, with bilingual setup, overlay, selection, notifications and update controls (#324).
- 🖥️ **Meet Meowcal Sub · 妙影.** The Chinese interface adds 妙影 to the familiar name, with a rounded layered-card icon across the app, tray and installers. English keeps Meowcal Sub, and both README pages have matching artwork and user guides (#324).
- 🎛️ **Get watching with fewer distractions.** Setup focuses on model terms, download progress and a sample check; Home offers Select subtitle area and Start with saved area. Save and exit keeps a selection for later, and About brings version and license details together (#322, #323).

## Fixes and improvements

- Home keeps its layout steady while selecting, starting and showing notices; Settings confirms saved changes without leaving a permanent message (#323).
- Local logs offers Off, Basic and Verbose; Basic remains the default, while opt-in Verbose retains screenshots and subtitle text locally within a separate 256 MiB budget (#317, #320).
- Available updates show up to three readable highlights with a link to the full release notes (#321).
- English and Chinese installation, troubleshooting and FAQ instructions now follow the current controls (#324).

## ⚠️ Known limitations

- The app translates visible screen text, not audio. OCR and translation can still make mistakes; this release keeps Meowcal Core v0.2.2 and the existing HY-MT model.
- Verbose logs can contain private screen content and slow capture. Turning them off stops new records but does not erase existing files; review files before sharing.
- GitHub installers are not Authenticode-signed. Windows SmartScreen may show an unknown-publisher warning (#62).
- ARM64 GPU translation retains the validated Adreno X1-85 / driver 31.0.148.0 boundary (#105, #215).
