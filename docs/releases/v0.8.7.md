# Meowcal Sub v0.8.7

This release improves subtitle context recovery, setup and settings, and adds
native Microsoft Store packages alongside the GitHub installers.

## Fixes and improvements

- Repeated output from an earlier subtitle is rejected. Managed contextual
  requests can retry without context; successful recovery explains that context
  is off for the session. Scene expiry still works after history compaction
  (#243).
- Setup failures can be retried, progress remains visible until work finishes,
  and compact windows keep their final controls reachable. Language and area
  controls stay locked while a session starts or stops. Pending appearance edits
  remain unsaved until Save, and capture warnings survive window focus changes.
- Model notices use compact, expandable terms with accessible license and
  provider links. HY-MT terms are shown before setup (#62).
- The area selector encodes its desktop snapshot as opaque RGB with the fast
  PNG preset.
- Installers include Meowcal Core v0.1.4. Core partitions engine storage by
  client and profile, reuses verified model files, and reclaims stale versions.
  Removing application data also removes that application's Core storage (#252).
- x64 and ARM64 Store MSIX packages use Store-managed updates and separate
  default settings and engine storage from GitHub installations. Package logos
  match the application icon. Store availability depends on submission and
  certification; attaching MSIX files here does not publish a Store update (#62).

## Validation

Native x64 and ARM64 release packaging runs application tests and the real Core
handshake. Before this version bump, current-main preflight verified both
architectures' MSI, NSIS and production-identity MSIX packages, combined hashes,
and updater signatures. Hosted ARM64 Store lifecycle evidence covers signed
installation, upgrade, capture/OCR/translation/overlay, custom storage, reset,
uninstall and coexistence with the direct installation.

Native ARM64 authored subtitle fixtures covered equal-width cues and negative /
recovery scenarios for the context fix. These checks do not establish general
movie reliability, physical x64 behavior, or new Snapdragon GPU safety.

## Known limitations

- GitHub installers are not Authenticode-signed. Windows SmartScreen may show
  an unknown-publisher warning; updater signatures do not remove it (#62).
- GPU acceleration remains limited to the validated Adreno X1-85 and driver
  31.0.148.0. CPU fallback does not establish that the reported
  `SOC_CRITICAL_DEVICE_REMOVED` Windows stop error is resolved (#105, #215).
- White objects can still merge with subtitle characters. Coloured subtitles
  use the fallback only when no white text is readable in the selected area;
  draw the area tightly around them (#251, #254).
- First translation waits for model loading, and CPU latency varies by device.
  General screen text still uses subtitle prompt and change-detection rules
  (#181, #187).

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. Store MSIX uses an independent package version, 1.0.1.0;
the application version is 0.8.7. Store packages remain unsigned until Store
publication and are not replacements for the GitHub MSI/NSIS installers.
