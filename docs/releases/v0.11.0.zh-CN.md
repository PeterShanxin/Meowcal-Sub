# Meowcal Sub · 妙影 v0.11.0

[English](v0.11.0.md)

**看到字幕翻错了，可以直接在应用里告诉我们。** 点标题栏的「反馈」就能写报告。应用报错时，也可以点提示旁的「报告错误」。

## 主要更新

- **在应用里发送反馈。** 选好类型，写下遇到的问题，点「发送」就行。从错误提示打开时，报告会带上这次出错时已有的诊断信息。[#340](https://github.com/PeterShanxin/Meowcal-Sub/issues/340)
- **自己选要分享的内容。** 比如某句字幕翻错了，可以先看原文和译文，再决定要不要附上。你的描述和选中的材料会在电脑上加密，只有维护团队能查看。[#342](https://github.com/PeterShanxin/Meowcal-Sub/pull/342)

## 修复与改进

- 发送失败时，填好的内容会留在窗口里，方便重试。
- 发送成功后，可以打开对应的 GitHub 问题页面。页面只公开反馈类型、应用版本和编号。反馈处理完 30 天后，系统会自动删除报告和附件。

## 下载

| 你的电脑 | 安装程序 |
| --- | --- |
| Intel / AMD 处理器 | `Meowcal.Sub_0.11.0_x64-setup.exe` |
| 骁龙或其他 ARM 处理器 | `Meowcal.Sub_0.11.0_arm64-setup.exe` |

发布页也提供 MSI 安装包。两个架构均内置 Meowcal Core v0.2.2，可用 `SHA256SUMS.txt` 校验下载文件。Microsoft Store 版本通过认证后上架。

使用 GitHub 安装包时，Windows SmartScreen 可能提示「未知发布者」。[#62](https://github.com/PeterShanxin/Meowcal-Sub/issues/62)
