# Meowcal Sub v0.8.2

This release makes the Adreno GPU engine start more conservatively and keeps
an updated installation from asking for an engine it already has.

## Fixes

- **Engine after an update.** When an update brings a new Meowcal Core version,
  Home shows the engine as installed instead of "Engine not installed · about
  1.1 GB"; the first start copies the verified engine from the previous
  version without a download (#216).
- **GPU start checks its output.** On validated Adreno GPUs, a freshly started
  engine must translate a sample correctly before it is used. If the output is
  corrupt, the engine restarts on the CPU instead of failing setup or
  returning unusable translations (#105).
- **GPU start needs memory headroom.** The engine starts on the CPU when less
  than 4 GiB of memory or commit is available (#215).

## Windows / ARM64 notes

- Each installer carries Meowcal Core v0.1.2 for its architecture.
- GPU acceleration remains limited to the validated Qualcomm Adreno X1-85 with
  driver 31.0.148.0; other ARM64 hardware continues to use the CPU policy.

## Known limitations

- This release was tested on Windows 11 ARM64. The x64 installers pass the
  automated build and contract checks but were not run on x64 hardware.
- A Windows stop error (`SOC_CRITICAL_DEVICE_REMOVED`) occurred during a GPU
  engine session on the validated Adreno machine (#215). Its cause is not
  established, and the changes above are not claimed to prevent it.
- A GPU engine can still start producing corrupt output after it has passed
  its start check (#105).
- The first start of translation after launching the app waits for the engine to
  load: about 8 to 20 seconds on the measured machine, longer under memory
  pressure.
- After an in-app update the taskbar can keep showing the previous app icon
  until Windows Explorer restarts.
- Subtitles made only of numbers can resemble a counter and wait about two
  seconds before they are shown.
- General text is translated with the same prompt as subtitles, so rows of
  short UI labels can come back loosely translated (#181).
- With **Translate any text** on, deciding whether on-screen text has changed
  still uses the rules built for subtitles (#187).
- Installers are not Authenticode code-signed, so Windows SmartScreen may
  still show an unknown-publisher warning.

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The local runtime and model require a one-time
download.
