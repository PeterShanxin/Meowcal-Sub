# Meowcal Sub v0.12.0

[简体中文](https://github.com/PeterShanxin/Meowcal-Sub/blob/v0.12.0/docs/releases/v0.12.0.zh-CN.md)

**Check for updates without switching how you installed Meowcal Sub.** Microsoft Store installs update through the Store, and GitHub installs keep their in-app update flow.

## ✨ Highlights

- 🛟 **Updates stay on your channel.** All editions check at startup at most once a day, or whenever you select **Check for updates**. The Store edition opens Microsoft Store; a GitHub installer continues to update in the app (#353).
- 🖥️ **Download a portable ZIP.** Choose x64 or ARM64, extract it, and start Meowcal Sub without an installer. When a newer ZIP is available for your computer, the app opens its download so you can extract it yourself (#353).

## Fixes and improvements

- The home screen keeps subtitle language labels next to their controls on short or zoomed-in windows (#352).
- Settings offers a retry if it cannot load your saved choices, and the update panel shows extra release details when available (#352).
- A new error report can start with an empty description even if an earlier draft did not pass validation (#352).
