# Meowcal Sub v0.8.8

This release makes capture restart and engine status more reliable, and keeps
OCR capture inside the area you selected. It also prepares the first automatic
Microsoft Store submission from a published GitHub release.

## Fixes and improvements

- Stop finishes the previous capture session's cleanup before acknowledging it.
  Starting again immediately no longer inherits a pending OCR task or the old
  session's subtitle output (#270).
- Engine status stays steady during ordinary translation. Repair and installation
  show a busy state and block Start until the engine is ready again; completed
  operations clear the transient state (#271).
- Confirming a capture area keeps its exact selected bounds instead of adding
  padding. Widen a very tight selection yourself if it clips a character
  (#275, #274).
- The Store update also includes improvements first released on GitHub in
  v0.8.7: rejection of stale contextual subtitles, recoverable setup and clearer
  model notices. It bundles Meowcal Core v0.1.4 with separate application
  storage; Core is not updated in this release.
- The GitHub release includes x64 and ARM64 Store MSIX packages. After the
  release is published, the enabled Store workflow verifies their provenance,
  stages both packages and the canonical listing icon, and requests Microsoft
  certification with publication after approval. Store availability depends on
  Microsoft's certification; the attached MSIX files alone do not install the
  Store update.

## Validation

The capture restart fix passed authored native ARM64 stop, immediate restart,
OCR, translation and visible-overlay acceptance. The readiness and exact-area
changes passed focused native Windows scenarios on their reviewed commits.
Hosted Windows x64/ARM64, Linux development and CodeQL checks passed on the
merged main commit. Store lifecycle checks passed on the reviewed integration
heads. These results do not establish a general
translation speedup, physical x64 acceptance or new Snapdragon GPU safety.

## Known limitations

- GitHub installers are not Authenticode-signed. Windows SmartScreen may show an
  unknown-publisher warning; updater signatures do not remove it (#62).
- ARM64 GPU acceleration remains limited to the validated Adreno X1-85 and
  driver 31.0.148.0. The x64 runtime uses Vulkan without that Adreno gate. CPU
  fallback does not establish that the reported
  `SOC_CRITICAL_DEVICE_REMOVED` Windows stop error is resolved (#105, #215).
- White objects can merge with subtitle characters. The coloured-subtitle
  fallback runs only when no white text is readable in the selected area; draw
  the area tightly around subtitles (#251, #254).
- First translation waits for model loading, and CPU latency varies by device.
  General screen text still uses subtitle prompt and change-detection rules
  (#181, #187).

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The independent Store package version is 1.0.2.0; the
application version is 0.8.8. Store MSIX packages are signed by Microsoft only
after Store submission and certification, and are not substitutes for the
GitHub MSI/NSIS installers.
