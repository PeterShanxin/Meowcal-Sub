# Meowcal Sub v0.11.0

[简体中文](https://github.com/PeterShanxin/Meowcal-Sub/blob/v0.11.0/docs/releases/v0.11.0.zh-CN.md)

**You can now report a subtitle problem right where you see it.** Open Feedback in the title bar, or choose Report error beside an error message.

## ✨ Highlights

- 🛟 **Send a report from the app.** Choose a feedback type, describe what happened and select **Send**. When you open the form from an error, it includes the available diagnostics for that error (#340).
- 🔒 **Choose what to share.** For a translation that looks wrong, you can preview the original line and its translation before attaching them. Your description and selected materials are encrypted on your PC. Only the maintenance team can read them (#342).

## Fixes and improvements

- If a send fails, your draft stays in the form so you can try again.
- After delivery, you get a link to the public issue. It shows the feedback type, app version and reference number. The report and attachments are automatically deleted 30 days after the team closes the issue.
