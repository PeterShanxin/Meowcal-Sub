# Meowcal Sub · 妙影 v0.12.0

[English](https://github.com/PeterShanxin/Meowcal-Sub/releases/tag/v0.12.0)

**更新不必换安装渠道。** 微软商店版通过商店更新，GitHub 安装版仍能在应用内更新。

## ✨ 亮点

- 🛟 **按原渠道更新。** 各版本每天启动时最多自动检查一次，也可以手动检查。商店版会打开微软商店，GitHub 安装版仍在应用内更新（#353）。
- 🖥️ **可下载便携 ZIP。** 选 x64 或 ARM64，解压后就能打开妙影，无需安装。发现适合你电脑的新便携包时，应用会打开下载链接，由你手动解压（#353）。

## 修复与改进

- 窗口较矮或放大后，首页的字幕语言标签仍会贴着各自的选项（#352）。
- 设置读不到已保存的内容时可以重试；新版本有更多更新内容时，可以展开查看（#352）。
- 上一份草稿未通过检查，也能从错误提示打开新的反馈表单，并从空白描述开始（#352）。

## 📦 下载

| 电脑 | 安装程序 | 便携 ZIP |
| --- | --- | --- |
| Intel / AMD | `Meowcal.Sub_0.12.0_x64-setup.exe` | `Meowcal.Sub_0.12.0_x64-portable.zip` |
| 骁龙等 ARM 处理器 | `Meowcal.Sub_0.12.0_arm64-setup.exe` | `Meowcal.Sub_0.12.0_arm64-portable.zip` |

也有 MSI 安装包。两个架构均内置 Meowcal Core v0.2.2，可用 `SHA256SUMS.txt` 校验下载。微软商店版以上架审核为准。

GitHub 安装包可能触发 Windows SmartScreen 的未知发布者提示。[#62](https://github.com/PeterShanxin/Meowcal-Sub/issues/62)
