# Meowcal Sub v0.8.4

This release adds a setting that keeps the translation engine off the GPU and
keeps static watermarks out of subtitles after brief OCR dropouts.

## New

- **Run the engine on CPU only.** Settings → Engine and updates has a switch
  that starts the translation engine without GPU offload on both ARM64 and x64.
  Changing it restarts the engine with the new choice. Use it if translations
  come out garbled or the PC stalls while the engine runs. Turning it off
  restores automatic acceleration unless the app switched to CPU after a GPU
  failure during this session.

## Fixes

- **Watermarks stay suppressed.** A static watermark that was already filtered
  out is no longer shown as a subtitle again when Windows OCR briefly returns
  empty frames. New dialogue is still admitted after the dropout (#223).
- Dependency updates for the application and Meowcal Core source.

## Windows / ARM64 notes

- Each installer carries Meowcal Core v0.1.3 for its architecture, unchanged
  from v0.8.3. Downloaded runtime and model files are reused.
- GPU acceleration remains limited to the validated Adreno X1-85 with driver
  31.0.148.0; other ARM64 hardware uses CPU inference.
- Windows 11 ARM64 native testing of the watermark fix ran two 120-second
  authored subtitle fixtures: the watermark was admitted 0 times across 131
  post-warmup OCR frames, and all 35 dialogue cues were translated. These tests
  do not establish general movie reliability.

## Known limitations

- The cause of the Adreno numerical corruption remains unresolved (#105).
  Automatic CPU fallback and the CPU-only setting reduce GPU exposure but are
  not proven to prevent the reported `SOC_CRITICAL_DEVICE_REMOVED` Windows stop
  error (#215).
- The x64 installers receive automated build and contract checks; physical x64
  and long real-media playback were not validated for this release.
- First translation waits for model loading, which can take longer under memory
  pressure. CPU inference latency varies by device.
- General screen text still shares the subtitle prompt and change-detection
  rules (#181, #187).
- Installers are not Authenticode code-signed. Windows SmartScreen may show an
  unknown-publisher warning.

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The local runtime and model require a one-time download;
verified files from an earlier Core version can be reused.
