# Meowcal Sub v0.6.0

This release reshapes Meowcal Sub around one job: watching Chinese or Japanese
shows with private, local English subtitles.

## Highlights

- Introduces a compact cinematic Windows interface with a guided four-step
  setup flow.
- Makes Tencent HY-MT the supported translation engine in normal mode and
  manages its download, verification, startup, health, repair, and shutdown.
- Keeps model names, endpoint URLs, ports, and backend infrastructure out of
  the normal viewing experience.
- Improves Chinese OCR language detection and preserves source-only text as an
  explicit fallback rather than presenting it as a translation.
- Adds bounded translation validation, retry classification, cancellation,
  deduplication, and stale-result suppression.
- Fixes first-launch state races and restores the window without the visible
  center-then-jump behavior.
- Adds native ARM64 and x64 MSI/NSIS packaging plus synchronized version checks.

## Before installing

- Windows 11 is the supported target.
- Choose the ARM64 installer on Snapdragon/ARM Windows PCs and the x64 installer
  on Intel or AMD PCs.
- The installers are not yet code-signed, so Windows SmartScreen may show an
  unknown-publisher warning. Verify the download against `SHA256SUMS.txt`.
- The translation runtime and model require a one-time local download of about
  1.1 GB.

## Validation status

Automated checks, native ARM64 setup, managed-engine startup, and sample
translation have passed. The draft remains unpublished until clean install,
upgrade, x64 runtime, and a final real 30-minute episode test are recorded.
