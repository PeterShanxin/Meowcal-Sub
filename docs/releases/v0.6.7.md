# Meowcal Sub v0.6.7

A correctness release, and the first one most people will never download by
hand: 0.6.6 added the in-app updater, so **Settings → Updates → Check for
updates** will offer this one.

## The window no longer reopens as a small square

Meowcal Sub records where its window is so it can reopen there. 0.6.3 taught
that recording to ignore a minimised or offscreen window, because storing those
coordinates is what made the app reopen as a small square in a corner.

Saving settings had its own separate copy of that recording, without the
guards. So changing any setting while the window was minimised still stored the
minimised geometry, and the next launch showed the symptom 0.6.3 was supposed
to have removed. There is now one path, with the guards, used by both.

## Settings that did nothing are gone

`autoStart` and `startWithWindows` were stored in configuration and read back
as if they meant something. Nothing anywhere acted on either: there was no
registry entry, no startup shortcut, and no switch in the current interface to
reach them with. The app never started with Windows and could not have.

The curated redesign deliberately kept startup control out of Settings, so the
honest fix is to stop storing a decision the app does not act on rather than to
add a switch back. Both fields are removed. Existing configuration files keep
the keys harmlessly; nothing reads them.

If starting with Windows is wanted, it should arrive as a feature that works,
not as a setting that already claimed to.

## Also in this release

The fix that stops a stray character surviving beside a subtitle when Windows
returns it as its own line — shipped in 0.6.5, reported as issue #54 — now has
a regression test. The behaviour is unchanged.

`main.rs` no longer holds the logic for finding and starting the overlay host
process; that moved to the module that already owned the process. No behaviour
change.

## Known limitations

- `minimizeToTray` is stored and still not applied: closing the main window
  always hides it to the tray. The same class of defect as the settings removed
  above, and not yet resolved.
- The update check is manual. There is no notification when a release appears.
- Each band's translation is still shown in the single overlay rather than near
  the text it came from. Tracked as issue #57.
- Windows OCR splits some characters into their radicals. Tracked as issue #53.
- Capture is fixed to the primary monitor while the overlay covers every
  display. Tracked as issue #52. Single-monitor setups are unaffected.
- Installers are not code-signed. Beyond the expected SmartScreen prompt,
  Microsoft Defender has been observed deleting `meowcal-sub.exe` outright
  after installation, taking the Start Menu shortcut and uninstall entry with
  it. The detection is `Trojan:Win32/Bearfoos.A!ml` — a machine-learning
  heuristic, not a signature match, and a false positive. It presents as the
  app vanishing rather than as an antivirus warning. Until the binaries are
  signed, recovering needs an elevated `Add-MpPreference -ExclusionPath` for
  the install directory before reinstalling.

## Before installing

- Windows 11 is the supported target.
- Choose ARM64 for Snapdragon/ARM Windows PCs and x64 for Intel or AMD PCs.
- Verify manual downloads against `SHA256SUMS.txt`.
- The local translation runtime and model require a one-time download of about
  1.1 GB.
