# Meowcal Sub v0.9.1

**Fast dialogue keeps its place in the translation queue.** Stable subtitles can
start translating while the source is still visible, and late answers get time
on screen before the next translation takes their place.

## ✨ Highlights

- 🎯 **Keep short replies and small changes.** Single Chinese characters,
  negations and changed numbers stay distinct. Fast dialogue is no longer
  blocked by a fixed caption-rate limit (#59).
- 🖥️ **Steadier subtitles.** Translations appear in order with a fixed bottom
  position and a reading interval based on source duration, text length and
  delay. Pausing the video does not keep translating the same line (#59).
- 🖥️ **Confirm the right area.** Subtitle selection follows the main window's
  monitor. Confirm the area before starting; switching monitors requires a new
  selection (#52).

## Fixes and improvements

- Stable new subtitles wait for a busy translator instead of being refused.
- OCR confirmation uses capture time, so slow processing does not turn
  consecutive readings into a false gap.
- Capture pacing adjusts within bounds to measured recognition cost.
- A held subtitle can retry after a recoverable engine or connection failure;
  successful translation stops further retries.
- A wrong-language answer gets one corrective request within the original
  attempt and time budget.
- The overlay distinguishes a quiet subtitle area from slow or unavailable
  translation without repeatedly interrupting playback.
- Update metadata checks have a deadline, while an installer download keeps
  its own lifetime.

## ⚠️ Known limitations

- Very fast subtitles can still outpace translation on a busy PC. Keep the
  selected area close to the original subtitles and leave CPU and memory
  headroom for the player.
- Credit names may also be translated: preserving fast dialogue takes priority
  over excluding a changing list of names.
- OCR and translation can still make mistakes. This release does not change the
  HY-MT model or the bundled Core version.
- GitHub installers are not Authenticode-signed. Windows SmartScreen may show
  an unknown-publisher warning (#62).
- ARM64 GPU translation retains the validated Adreno X1-85 / driver
  31.0.148.0 boundary (#105, #215).

<details>
<summary>How this release was tested</summary>

Queue regressions cover rapid dialogue, single-character replies, changed
negations and numbers, paused captions, bounded recovery and cancellation.
The held-caption recovery regression first fails with the previous retry
policy, then passes with the fix; deterministic output rejection remains
non-retryable.

Native Windows capture, PP-OCRv6, managed translation and Overlay were checked
on Snapdragon X Elite hardware using authored dialogue and negative/recovery
fixtures. Recorded movie-band results and their limits are documented in
[#315](https://github.com/PeterShanxin/Meowcal-Sub/pull/315). Short labeled clips
do not establish reliability for every film or caption style.
