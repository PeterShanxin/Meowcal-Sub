# Meowcal Sub v0.9.0

**Subtitles are read right, and each one is translated once.** A new built-in
recognizer, PP-OCRv6, reads an unchanged subtitle the same way from frame to
frame, so a line no longer flickers through several translations.

| Recorded Chinese clip, 40 subtitles  | Windows OCR | PP-OCRv6 |
| ------------------------------------ | ----------: | -------: |
| Final translation from an exact read |          27 |   **40** |
| Subtitles never translated           |           3 |    **0** |
| Windows language pack needed         |         Yes |   **No** |

## ✨ Highlights

- 🎯 **PP-OCRv6 text recognition.** Runs on your PC inside Meowcal Core and
  reads Chinese, Japanese, English, Spanish, French and German without a
  Windows language pack (#59).
- 🎛️ **One-choice profiles.** **Settings → Profile** offers **Automatic**
  (PP-OCRv6, translation on the graphics card when it can) and
  **Compatibility** (Windows OCR, translation on the CPU). The individual
  choices are under **Advanced**. Korean subtitles always use Windows OCR.
- ⚡ **Ready sooner.** Confirming a subtitle area starts loading the
  translation engine, so it is often ready before you press Start.
- 🛟 **The engine restarts itself.** If the translation engine stops during a
  session, Meowcal restarts it after 30 seconds, then after 1 and 2 minutes,
  then every 5 minutes.
- 🖥️ **Exit from the overlay.** An Exit control on the subtitle overlay stops
  translation and returns to Home. It sits outside the captured area and works
  from the keyboard (#92).

## Fixes and improvements

- When translation only falls behind because the PC is busy, the overlay says
  so instead of reporting the engine as unavailable.
- While translation runs on the CPU, PP-OCRv6 uses two threads instead of four
  to leave room for the translation engine.
- The overlay stays on the monitor that holds the selected subtitles when a
  second display sits left of the primary one.
- Small text in the subtitle row, such as a channel watermark, is left out of
  the subtitle that PP-OCRv6 reads.
- Right after Meowcal starts, Home no longer reports an installed translation
  engine as missing for a moment (#309).
- On x64 PCs, translation uses the graphics card only when the PC has a
  discrete GPU. PCs with only integrated graphics translate on the CPU, which
  was faster in testing (#305).

## ⚠️ Known limitations

- PP-OCRv6 needs more CPU than Windows OCR (about 50-100 ms per frame on a
  Snapdragon X, against 5-30 ms). If other programs keep the CPU busy while
  translation runs on the CPU, translation can fall behind with either
  recognizer.
- A watermark or sign in the selected area can be translated on its own while
  no subtitle is showing. Draw the area tightly around the subtitles.
- Windows SmartScreen may warn about an unknown publisher, because GitHub
  installers are not Authenticode-signed (#62).
- ARM64 GPU translation is limited to the validated Adreno X1-85 with driver
  31.0.148.0 (#105, #215). On x64, a discrete GPU whose Vulkan driver does not
  work can leave translation on the CPU while Settings shows the GPU.

<summary>How this release was tested</summary>

Both recognizers were read through the app's recognition path against a
source-built Meowcal Core 0.2.0 on Windows ARM64, and the app's subtitle policy
was replayed over a recorded Chinese clip and synthetic Chinese and English
clips; see
[the OCR stability experiment](../plans/2026-11-05-ocr-stability-experiment.md).
An installed release build was run on a Snapdragon X Elite against the
band-gate fixture with translation forced to the CPU: both recognizers
translated 29 of 30 cues while idle and while four other threads kept the CPU
busy, and translation fell behind with either recognizer at eight busy threads.
Hosted Windows x64 and ARM64 install, upgrade and translation checks, Linux
development checks and CodeQL passed on the release commit.
