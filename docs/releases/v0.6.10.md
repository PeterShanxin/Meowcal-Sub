# Meowcal Sub v0.6.10

This release adds automatic update checks and fixes an overlay recovery gap
found in the field.

## Highlights

- The app now checks for updates once a day in the background, with a subtle
  indicator in Settings when a new version is available. Automatic checks
  never download or install anything; you still start an update yourself.

## Reliability / updater improvements

- Clicking "Check for updates" while an automatic check is already running
  now joins that check instead of starting a duplicate request.
- An automatic check that fails to read your current settings no longer
  overwrites them with defaults.
- The overlay now detects a wedged WebView renderer and recovers it with a
  bounded reload instead of staying invisible for the rest of the session.

## Windows / ARM64 notes

- No changes to the ARM64 GPU-offload path since v0.6.9. GPU acceleration
  remains limited to the validated Qualcomm Adreno X1-85 with driver
  31.0.148.0; other ARM64 hardware continues to use the CPU policy.

## Maintenance

- Continued internal refactor of the Rust application lifecycle and
  translation pipeline, and of the frontend module boundaries, with no
  intended behavior change.
- Governance, CI, and dependency maintenance, including moving the pinned
  GitHub Actions (checkout, setup-node, upload-artifact, download-artifact)
  and several Rust/npm dependencies to their current major versions.

## Known limitations

- Installers are not Authenticode code-signed, so Windows SmartScreen may
  still show an unknown-publisher warning.

Choose the installer matching your Windows architecture and verify downloads
with `SHA256SUMS.txt`. The local runtime and model require a one-time
download.
