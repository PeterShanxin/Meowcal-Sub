Install Foundry Local

Foundry Local is Microsoft's local LLM runtime that powers on-device AI translation. It runs entirely on your machine for privacy and speed.

This command will be run in PowerShell:
winget install Microsoft.FoundryLocal --accept-source-agreements --accept-package-agreements

A PowerShell window will open to run the installer. You may be prompted for administrator access (UAC).
